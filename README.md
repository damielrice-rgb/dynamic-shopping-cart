This is a dynamic shopping cart that allows user's to add a product, price, and render the object on the page. I used createElement to create li's for the product objects to append to. Then I used appendChild() to put the li in the ul. I created a function that adds the total each time a product is added to the array. I wrote a if statement to compare if the value of the input is empty, and if it is show a alert message that notifies the user.
